Working rule:
- Start with the seller country.
- If the customer is in a different covered country, also check that country file for invoice wording, VAT-number expectations, and practical risk flags.
- Treat each file's **invoice fields / wording** section as a split between what is **usually mandatory / core** and what is **recommended practical detail**.
- If facts are incomplete or the rule seems to depend on a regime election, e-invoicing rollout, threshold update, or local practice, say so and escalate.

These notes are intentionally compact. They are for practical agent guidance, not a substitute for local tax advice.
